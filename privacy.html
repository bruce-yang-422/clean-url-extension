Clean URL｜乾淨連結
隱私權政策

最後更新日期：2026 年 10 月 19 日

「Clean URL｜乾淨連結」（以下簡稱「本工具」）非常重視您的個人隱私。本隱私權政策適用於瀏覽器擴充功能、網頁版與 PWA，說明本工具如何處理您的資訊。

1. 資料收集與處理

本工具的網址清理功能為 100% 本地端（Local-only）運作。本工具不會收集、儲存、記錄、追蹤或傳輸您的個人身分資訊、瀏覽歷史紀錄、網路活動或輸入的網址，也不會讀取或上傳剪貼簿既有內容。

擴充功能僅在您主動開啟彈窗時讀取目前分頁的網址；網頁版與 PWA 僅處理您主動貼上或透過系統分享傳入的網址。原始網址與清理結果只存在當次介面的記憶體中，不寫入 localStorage、資料庫、清理歷史紀錄或離線快取。系統分享由本機 Service Worker 接收，不會將分享內容傳至網站伺服器。

PWA 的離線快取僅包含應用程式、清理規則、圖示與本政策頁面，不包含您輸入的網址。您可透過瀏覽器清除此網站資料來移除離線快取。本工具不使用分析追蹤服務、追蹤 Cookie、外部字型或遠端清理 API。

2. 權限使用說明

  • activeTab：僅在您主動點擊擴充功能圖示開啟介面時，於本機端讀取當前分頁的 URL，用於辨識並過濾追蹤參數。
  • clipboardWrite：僅在您點擊「複製乾淨連結」按鈕時，將過濾後的網址寫入您的本機剪貼簿。

網頁版與 PWA 不會讀取您正在瀏覽的其他分頁，只會在您按下複製按鈕時，透過瀏覽器的剪貼簿功能寫入清理結果。剪貼簿後續的保存或同步，依您的作業系統與剪貼簿設定運作。

3. 第三方分享

本工具不在伺服器端收集或儲存您輸入的網址與清理結果，也不會將您的個人資訊出售、交換、出租或揭露給任何第三方。

網頁版與 PWA 的靜態檔案由 GitHub Pages 提供。首次開啟或更新網站時，瀏覽器會向託管服務發出一般網站連線請求；託管服務可能依其政策處理 IP 位址等連線資訊。您貼上或清理的網址不會隨這些請求傳送。可參閱 GitHub 隱私權聲明。

4. 聯絡方式

如果您對本隱私權政策有任何疑問，歡迎透過 Clean URL 擴充功能支援頁面與開發者聯繫。公開留言時，請避免附上個人資料或含敏感資訊的網址。
